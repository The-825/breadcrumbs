# Checklists

Operational checklists, ready to copy and use. Run `pr-discipline.md` before opening a PR, `pre-push.md` before every push, and `continuity-sweep.md` after changing a fact other surfaces cite. Run `ui-delivery-evidence.md` before delivering an interface. UI review time depends on the journeys and states you need to verify.

| File | What it is |
|---|---|
| [pr-discipline.md](pr-discipline.md) | Pre-open checklist for PR shape: one concern, the ~500-line split question, intent-tagged titles, feature-slug branches, the scope-forcing body template. |
| [pre-push.md](pre-push.md) | Verify-before-push: re-read the diff, run the cheapest covering check, confirm scope. Includes the change-type to check table. |
| [continuity-sweep.md](continuity-sweep.md) | After-change sweep: drift check (every citing surface matches the canonical source) plus completeness check (surfaces that should now reflect the change and do not). |
| [ui-delivery-evidence.md](ui-delivery-evidence.md) | Interface review worksheet: actual controls, keyboard behavior, responsive states, supported claims and preserved copy meaning. Manual review, not executable enforcement. |
