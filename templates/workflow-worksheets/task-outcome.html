A simple everyday view

  • Next: one actionable step with its prerequisite.
  • Waiting: missing input, permission, result or validation.
  • Done: the result met its acceptance rule, with evidence.

A person or an eligible agent can do a step. Keep the task ID, result, evidence and completion rule stable across worker changes. Humans remain accountable for goals and consequential decisions.

Runtime is separate

This page has no executor, account connection, task storage or board updates. A process becoming idle or offline cannot change the task's acceptance.

Ownership, permissions and interrupted work

Supporting ownership and runtime permissions belong to the execution system. The page grants no authority. If work is interrupted, inspect the saved result and resume only the missing step. An uncertain effect needs reconciliation before retry.

Pausing must preserve evidence. Reopening must retain prior acceptance as history and flag affected child and parent validation. Automatic rollup, pause/reopen controls and authenticated validation are not implemented by this example.

Before claiming that it saves work

Compare the same task with the existing checklist or spreadsheet. Include setup, repeated corrections, supervision, maintenance and actual service costs. No measured savings or universal benefit is claimed here.
