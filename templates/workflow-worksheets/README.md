# Workflow worksheets

These copy-and-adapt worksheets help a small team make work visible, request a bounded change, and hand routine upkeep to another owner. Each file stands alone. They are pattern-only documents, not software or an approval system. The adopter supplies the figures, roles, dates, and review rules.

Use role names instead of personal details where possible. Keep credentials and sensitive records in the system that already controls access, and link to an approved location only when the reader can access it.

| Worksheet | Use it to |
|---|---|
| [Workflow capacity estimator](workflow-capacity-estimator.md) | Compare available time with recurring work and planned demand. |
| [Small-change request](small-change-request.md) | Define a limited process or tool change, its owner, review, and recovery plan. |
| [Workflow maintenance handoff](workflow-maintenance-handoff.md) | Transfer recurring upkeep with clear triggers, checks, and escalation points. |

Start with the smallest worksheet that answers the current question. Mark unknowns as unknown, assign an owner to resolve them, and set a review date before treating estimates as commitments.
