# Breadcrumbs web visual system

Status: ships with the public site. The tokens extend the established 825 and
Architect's Sandbox visual language to Breadcrumbs.

## Palette

| Token | Value | Use |
|---|---|---|
| Forest | `#1b4332` | Page and navigation ground |
| Forest mid | `#245741` | Panels and controls |
| Jade | `#2d6a4f` | Depth and gradients |
| Jade light | `#3d7c5e` | Supporting surfaces |
| Antique gold | `#c79a3f` | Primary accent and headings |
| Deep gold | `#b5832a` | Secondary accent |
| Ivory | `#f4f1e8` | Primary text |

## Type

- Georgia is the editorial display face for the brand, headings, and metrics.
- Arial is the working face for navigation, body copy, forms, and tables.
- Uppercase gold eyebrow labels identify the current trail.

## Shape and interaction

- Corners are restrained rather than pill-heavy.
- Gold outlines identify key boundaries and active paths.
- Pills are reserved for metadata, not general decoration.
- Tables remain dense and readable because the site is a working evidence surface.

## Accessibility

- Ivory and gold text are used only on tested dark-green surfaces.
- Focus remains visible with the gold accent.
- The Trail Map has a text alternative, and all data remains available in tables.
- Reduced-motion preferences disable smooth scrolling.
