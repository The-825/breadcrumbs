Hidden curriculum

The failure path teaches the design.

Unknown is a state

After dispatch, a timeout can mean the effect happened and the receipt was lost. Preserve the reservation, mark the outcome uncertain, and reconcile before any new action.

Identity comes first

Authenticate the participant before deciding what is shared. Personal and shared memory are separate scopes, and read permission never implies write or transfer authority.

Recall needs a path

A useful memory result names its owner, provenance, correction state, ranking path, stop reason, and warnings. Similarity alone is not governance.

Discovery has a budget

Measure completeness, calls, bytes, latency, and over-discovery. A shorter tool list is not better when it hides controls or widens the surface.

Keep a holdout

Self-improvement needs a fixed budget, full edit history, leakage check, untouched evaluation set, and a stop rule written before the run.

Adopt the gap

Search the owning system first. Take the smallest missing mechanism, test it against the baseline, and leave the rest of the external platform outside the boundary.
