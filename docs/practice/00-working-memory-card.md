# Start with a working memory card

**Status:** public, pattern-only exercise. This page ships as documentation. It does not enable persistent storage, capture messages, or grant an agent access to any account.

**Assumes:** you have a text editor and can review a card before using it. Use only the synthetic example here. For real work, keep the card inside an authorized system and decide its storage, access, retention, and deletion rules before saving sensitive details.

An assistant can carry forward a confident but outdated detail. A small card with source pointers, unknowns, and a correction path gives you something to check before the next task.

## Fictional card

```text
Purpose: Prepare a community workshop using approved materials.
Preferences: Keep summaries short. Show the source for every requested action.
Active project: Saturday workshop planning.
Open question: Who will bring sign-in sheets?
Source links: fictional inbox, rows M1 to M5; no live links.
Unknowns: Sign-in-sheet owner and deadline are not stated.
Last reviewed: not yet reviewed.
Review again: Before the next exercise or when a source changes.
Expires: After the fictional workshop; review whether to retain the note.
Correction path: Mark the wrong line, cite the source, ask the owner to confirm,
then replace the line and note what changed. Do not silently preserve the old claim.
```

## Your action

Copy this card into a temporary local note. The `Source links` field points to the [fictional inbox](01-inbox-to-briefing.md#fictional-inbox), rows M1 to M5. Review each line against those messages, then set `Last reviewed` to your review time. Keep only the minimum cues needed for the next task: a preference, current project, open question, source pointer, and explicit unknown. If a line lacks support, change it to `unknown` or remove the unsupported claim. Do not paste real inbox bodies, transcripts, personal details, or private source links into this exercise.

## Human check

Ask a second reader to use the source pointers to check the open question and preferences. The preferences are an example instruction for this exercise, not a claim about a real person. If they find a mistake, follow the correction path and show the revised line before using the card again. A saved card is still only a reviewed note, not proof that an automated memory service is active.

The kit's [memory desk](../memory-desk.md) and [copyable memory tools](../../templates/memory-desk/README.md) cover retrieval and maintenance in a repository. The [session-state template](../../templates/SESSION_STATE_TEMPLATE.md) covers longer handoffs. This card is the smallest practice before either one.
