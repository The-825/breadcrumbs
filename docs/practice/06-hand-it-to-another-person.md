# Hand it to another person

**Status:** public, pattern-only exercise. The kit ships [handoff templates](../../templates/SESSION_STATE_TEMPLATE.md) and [workflow worksheets](../../templates/workflow-worksheets/README.md), but no access-grant or task-running service.

**Assumes:** a fictional successor can read the reviewed artifacts from this series. Use a synthetic copy for the rehearsal. Real access stays with the owning system's authorized process.

A handoff that lists files but omits the next safe action leaves the successor guessing. Give them a one-page route from starting file to exception path.

## Your action

Write one handoff page with: purpose, starting file and revision, access request path, current owner, operating steps, source of truth, exception path, open decisions, and one safe first task. Use the reviewed [briefing](01-inbox-to-briefing.md), [action list](02-meeting-to-action-list.md), [transfer receipt](03-automate-one-handoff.md), [count card](04-make-a-number-explainable.md), and [change receipt](05-review-a-change-before-release.md) where they exist. Mark missing artifacts `not available`.

For the rehearsal, make the first task: find the source row for the synthetic `paper` item and report its quantity with a source pointer. This requires reading, not editing or sending. Name whom to contact if the source is missing or conflicts with the card.

## Human check

Ask someone who did not write the page to complete that safe task using only the handoff. Record where they pause, ask, or use a stale file, then revise the page. The test passes when they can find the source row, give the quantity, and identify the exception path without guessing. Do not infer that this rehearsal proves a real access setup works.

**Next:** revisit the [working memory card](00-working-memory-card.md), then repeat the briefing with another synthetic batch using what the handoff test taught you. For larger shared work, use the kit's [cooperative evaluation method](../cooperative-intelligence-evaluation.md).
