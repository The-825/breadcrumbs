# AGENTS.md

This repo's agent instructions live in **[CLAUDE.md](CLAUDE.md)**. That file is the
single source of behavioral truth for every coding agent working here, regardless
of vendor or tool. Read it completely, top to bottom, before touching anything.

Then:

1. **[SESSION_STATE.md](SESSION_STATE.md)** for the current working state (active
   branch, in-flight edits, next steps, pending decisions).
2. **[planning/DECISIONS.md](planning/DECISIONS.md)** for durable rulings already
   made, so you don't re-litigate a decided question.

This repo is a **public, world-readable kit**. The integrity floor in CLAUDE.md
(no private/production/personal content, no unsourced numbers, no plagiarized
content) applies to every file you write or edit here, with no exceptions for
small changes.

Do not duplicate instructions into this file. It is a router only; content here
would drift from CLAUDE.md, which stays authoritative.
